# VeriForge Gateway

The VeriForge Gateway is a reference implementation of the VeriForge verification protocol.

It is designed as an MCP-native gateway that:
- Receives model outputs
- Determines verification requirements
- Routes outputs to appropriate verifiers
- Aggregates verification results
- Returns certified or qualified responses

This repository is currently focused on architecture, interfaces, and design discussion.
